# Annotate (アノテート)

> **"Achieving true peace requires a sense of crisis. Complacency creates stagnation where nothing new can be created."**

Annotate は、現代の肥大化したITインフラ、過剰なメモリ、そして「過去の記憶（データ）」に安住して変化を拒む現代人の姿勢に対する、極めて挑戦的なアンチテーゼとして設計された、**32KBの極小メモリ環境で駆動する自律創発型LISPシステム（言語・ツール・極小OSへのロードマップ）**です。

かつてデモシーン（Megademo）やリアルタイムVJカルチャーが持っていた「最小限のリソースから最大の美を引っ張り出す」という野生のクリエイティビティを、AIとロボティクスにおける「真の自律知能」の設計思想へと昇華させました。

## 👁️ 哲学：なぜ、いま「引き算」なのか？

現代のAIやソフトウェアは、数GB〜数TBの膨大なメモリとデータという「過剰な報酬」を与えられ、先回りしてアシストされすぎています。しかし、認知科学が示す通り、過保護な環境は主体性と自律性を奪い、知能を退化させます。

Annotate は、システムから「記憶（変数・蓄積）」と「既存のインフラ（レガシーOS/ライブラリ）」を徹底的に取り上げます。過去の栄光（データ）に頼れない「飢餓状態」と「リアルタイムの物理的摩擦」を意図的に作り出すことで、システム自身がその場で思考を組み立て、インフラすらも自給自足で「創発」せざるを得ない環境を強制します。

**足りないからこそ、埋めようとして真の知能が駆動する。**

## 🧱 アーキテクチャと極小の「原子」たち

Annotate は、32KB（32,768バイト）の物理メモリ空間をトポロジカルに使い切るマイクロカーネル設計を採用しています。

- **8KB: インタプリタ・コア (EVAL/APPLY 循環ループ)**
- **4KB: OBLIST / スタック領域 (XOR極小ハッシュ照合)**
- **20KB: 自由セル空間 (4バイト×5,000セルのポインタの海)**

### 1. 記憶を持たない即興演算 (EVAL/APPLY)
グローバル変数を一切排除し、入力された式を「今、ここ」の文脈（環境引数リスト）だけで評価します。計算が終わった瞬間にポインタが外れ、すべては綺麗にリセット（忘却）されます。

### 2. 記号の即時濃縮 (引き算ハッシュ)
文字列データを贅沢に保持するメモリはありません。入力された記号は、掛け算器すら使わない「ビットシフトとXOR」の原始的な反射回路により一瞬で4バイトのポインタへアノテート（注釈化）され、OBLISTで高速に照合された後、文字列自体は即座に忘却されます。

### 3. 100%の更地化 (マーク＆スイープGC)
5,000セルがゴミで窒息する前に、現時点で生存しているポインタのみをマークし、不要になった過去のデータ（ゴミ）を容赦なくすべて消去して「完全なゼロベースの更地」に戻す代謝システムです。

### 4. 1.44MBの大地 (仮想FDD)
32KBの身体を拡張するため、レガシーな3.5インチ2HDフロッピーと同じ容量（1.44MByte / 2,880セクタ）を持つ「バーチャルFDD（VFDD）」と直結。セクタ単位の動的ロードにより、必要な道具（ツール）をその瞬間だけ想起し、使い終わったらGCで完全に忘却するサイクルを回します。

## 📂 リポジトリの構成

- `/kernel` : C言語/機械語でストイックに記述された「Annotate」コア（EVAL、ハッシュ、GC）
- `/emulator` : 32KBメモリと1.44MBのVFDD空間を完全に再現した仮想VMシミュレータ（Python実装）
- `/vfdd` : セクタ0に「自作極小ファイルローダー」が書き込まれた、最初のブートディスクイメージ
